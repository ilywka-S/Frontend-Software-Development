Про проєкт

Мета проєкту

Вебзастосунок розроблено як навчальний STEM-проєкт. Він показує, як складні, хаотичні природні явища, зокрема лісові пожежі, можна моделювати за допомогою локальних правил на сітці, а не лише громіздких систем диференціальних рівнянь.

Для кого призначений

  • Студенти та дослідники: наочно побачити стохастичну природу поширення вогню.
  • Фахівці з пожежної безпеки: швидко оцінити ризики для гіпотетичних умов.
  • Служби планування реагування: зрозуміти, як погодні чинники впливають на час, що залишається для евакуації.

Технології

  • Фронтенд: Angular (standalone-компоненти, сигнали), TypeScript, Angular Router із вкладеними маршрутами до трьох рівнів.
  • Бекенд: Node.js, мінімальний REST API без сторонніх залежностей.
  • Модель: ймовірнісний клітинний автомат (окіл Мура) на сервері; результат відтворюється за зерном випадковості.
  • Візуалізація: HTML5 Canvas для карти та HTML/CSS для інтерфейсу.
  • Дані: набори у форматі NASA FIRMS, Copernicus DEM та ERA5; історія запусків зберігається у файлі на сервері.
